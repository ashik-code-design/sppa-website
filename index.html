About SPPA

SPPA (Students Practical Performance Assessment) is a college practical assessment application. It helps staff manage practical examinations, record student marks and maintain assessment information digitally.


The application consists of a Flutter mobile frontend and a Node.js REST API backend connected with MongoDB.
